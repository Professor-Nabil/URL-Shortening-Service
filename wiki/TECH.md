# Technical Stack - URL Shortening Service

This project utilizes the following technologies for robust backend development:

## Core Technologies

- **Runtime:** [Node.js](https://nodejs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## Framework & Libraries

- **API Framework:** [Express.js](https://expressjs.com/)
- **ORM:** [Prisma 6](https://www.prisma.io/)
- **Validation:** [Zod](https://zod.dev/)

## Database

- **Database:** [MariaDB](https://mariadb.org/) (Local development)

## Testing

- **Test Runner:** [Vitest](https://vitest.dev/)

## Tooling & Utilities (Essential Additions)

- **Execution:** [tsx](https://www.npmjs.com/package/tsx) (For seamless TypeScript execution)
- **Type Checking:** [tsc](https://www.typescriptlang.org/docs/handbook/compiler-options.html) (For static analysis)
- **Formatting:** [Prettier](https://prettier.io/) (For code consistency)
- **Linting:** [ESLint](https://eslint.org/) (For code quality)
- **Environment Management:** [dotenv](https://www.npmjs.com/package/dotenv) (For managing environment variables)
- **HTTP Client/Requests:** [Supertest](https://www.npmjs.com/package/supertest) (For integration testing Express endpoints)
- **Git Hooks:** [Husky](https://typicode.github.io/husky/) & [lint-staged](https://www.npmjs.com/package/lint-staged) (To enforce quality before commits)
